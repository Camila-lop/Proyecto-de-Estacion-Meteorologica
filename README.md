# Proyecto-de-Estacion-Meteorologica
Estación meteorológica basada en ESP32 que mide temperatura, humedad y presión (con los sensores: DS18B20, DHT22, BMP280). Almacena los datos localmente en flash con resiliencia offline, los sincroniza a la nube (ThingSpeak) cuando hay conexión, y los expone un panel web local con gráficos en tiempo real.
